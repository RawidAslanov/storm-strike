# ⚓ Storm Strike — как скачать на ноут

Игра залита на GitHub в **отдельную ветку** `storm-strike`.

## Скачать и запустить (скопируй в терминал)

```bash
git clone -b storm-strike --single-branch https://github.com/RawidAslanov/Barber-site.git storm-strike
cd storm-strike
npm install
npm run dev
```

Открой в браузере: **http://localhost:5173**

## Мультиплеер с другом

Терминал 1:
```bash
npm run server
```

Терминал 2 (если dev не запущен):
```bash
npm run dev
```

## Ссылка на GitHub

https://github.com/RawidAslanov/Barber-site/tree/storm-strike

Там все файлы игры: `package.json`, `src/`, `server/` и т.д.

## Важно

- Ветка `main` — это сайт барбершопа, **не трогай её**
- Ветка `storm-strike` — **только игра**, отдельно от сайта
- Позже можно вынести в репозиторий `storm-strike` (см. GITHUB_SETUP.md)
